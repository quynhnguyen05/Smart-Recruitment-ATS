# 2. 5 Job Description mẫu

## JOB-01 — Backend Developer

**Title:** Backend Developer

**Mô tả ngắn:**

Phát triển và bảo trì hệ thống backend, xây dựng RESTful API, xử lý dữ liệu và tích hợp với các dịch vụ khác. Phối hợp với Frontend Developer, QA và BA để triển khai các tính năng ổn định, bảo mật và có khả năng mở rộng.

**Required Skills:**

1. Java hoặc Python
2. Spring Boot hoặc Django/FastAPI
3. RESTful API
4. SQL và PostgreSQL/MySQL
5. Git
6. Docker
7. Kiến thức về software architecture
8. Unit Testing

## JOB-02 — Frontend Developer

**Title:** Frontend Developer

**Mô tả ngắn:**

Phát triển giao diện web responsive, chuyển thiết kế UI/UX thành giao diện thực tế và tích hợp với backend API. Đảm bảo hiệu năng, khả năng sử dụng và chất lượng code.

**Required Skills:**

1. HTML5
2. CSS3
3. JavaScript
4. TypeScript
5. React.js
6. REST API
7. Git
8. Responsive Web Design

## JOB-03 — UI/UX Designer

**Title:** UI/UX Designer

**Mô tả ngắn:**

Thiết kế trải nghiệm và giao diện người dùng cho sản phẩm web/mobile. Thực hiện user research, xây dựng wireframe, prototype và phối hợp với BA/Developer để đảm bảo thiết kế có tính khả thi.

**Required Skills:**

1. Figma
2. Wireframing
3. Prototyping
4. User Research
5. User Flow
6. Design System
7. Usability Testing
8. Interaction Design

## JOB-04 — QA Tester

**Title:** QA Tester

**Mô tả ngắn:**

Kiểm thử phần mềm nhằm phát hiện lỗi và đảm bảo sản phẩm đáp ứng yêu cầu nghiệp vụ cũng như yêu cầu chất lượng. Thực hiện test case, regression testing, API testing và phối hợp với Developer để xử lý defect.

**Required Skills:**

1. Manual Testing
2. Test Case Design
3. Regression Testing
4. Bug Reporting
5. API Testing
6. Postman
7. SQL
8. Jira

## JOB-05 — Business Analyst

**Title:** Business Analyst

**Mô tả ngắn:**

Thu thập, phân tích và quản lý yêu cầu từ các bên liên quan; mô hình hóa nghiệp vụ và chuyển đổi yêu cầu thành tài liệu mà đội phát triển có thể triển khai. Phối hợp với Product Owner, Developer và QA trong suốt vòng đời dự án.

**Required Skills:**

1. Requirements Analysis
2. Business Process Modeling
3. UML
4. BPMN
5. Use Case
6. User Story
7. SQL
8. Jira
